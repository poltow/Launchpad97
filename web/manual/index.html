Launchpad95 Complete Manual

Launchpad95 is an advanced control surface script for Ableton Live that transforms your Novation Launchpad into a powerful music production tool with step sequencers, instrument control, and device parameter editing. This manual covers every feature of Launchpad95 in detail.

Pro Session Mode

Advanced clip manipulation with 8 modifier buttons for copy, paste, delete, duplicate, quantize, record, and tempo control.

Drum Step Sequencer

16/32-step pattern sequencer with 5-level velocity, mute system, quantization (1/4 to 1/32), and combined/multinote modes.

Melodic Sequencer

7-note polyphonic sequencer with 4 editing pages: pitch, velocity (7 levels), length (7 values), and octave control.

Instrument Mode

Scale-based playing with 34 musical scales, 6 layout modes, Quick Scale access, Note Repeat, and intelligent drum rack detection.

Device Controller

Control any device parameter with 8 sliders, precision mode, parameter banks, and 4 device lock slots for instant recall.

Mixer Mode

Full mixing control with volume, pan, sends A/B, plus mute/solo/arm/stop for 8 tracks with 5 sub-modes.

Key Features

  • 7 Operating Modes: Session, Pro Session, Instrument, Device Controller, Drum Sequencer, Melodic Sequencer, Mixer
  • 34 Musical Scales: Western modes, pentatonics, blues, Japanese, Middle Eastern, and 8 new scales in v2.0
  • Full Ableton Integration: Clip launching, scene control, device parameters, transport
  • Hardware Support: Launchpad Original, Launchpad S, Launchpad Mini MK1 (legacy 3-color models only, no RGB)
  • Detailed Timing: Long press (500ms), double-click (250ms), very long press (2000ms) actions

Installation

Step 1: Download

Download the latest Launchpad95.zip from the official source.

Important: If downloading from GitHub, rename the folder to remove "-master" suffix. The folder must be named exactly Launchpad95.

Step 2: Copy Files

Windows

C:\ProgramData\Ableton\Live [version]\Resources\MIDI Remote Scripts\Launchpad95

macOS

Right-click on Ableton Live in Applications, select "Show Package Contents", then navigate to:

Contents/App-Resources/MIDI Remote Scripts/Launchpad95

Step 3: Configure Ableton Live

  1. Open Ableton Live (or restart if already open)
  2. Go to Preferences > Link, Tempo & MIDI
  3. Under Control Surface, select Launchpad95
  4. Set Input to your Launchpad MIDI port
  5. Set Output to your Launchpad MIDI port
  6. IMPORTANT: Enable Track for both Input and Output
Tip: "Track" must be enabled for MIDI input/output to get note feedback in Instrument mode and proper button lighting.

Step 4: Verify Installation

If installation is successful:

  • Launchpad buttons should light up
  • You should see "SESSION MODE" in Ableton's status bar
  • Pressing mode buttons (Session, User1, User2, Mixer) should change modes

Optional: Max for Live Helper

A Launchpad95Helper.amxd device is included in M4LDevice/ folder. This provides an on-screen display (OSD) showing current mode and settings. Not required for the script to work.

Enabling Debug Logs

For developers or troubleshooting, you can enable detailed logging:

  1. Open the Python file you want to debug (e.g., MainSelectorComponent.py)
  2. Find commented lines like: #Live.Base.log("message")
  3. Remove the # to uncomment and enable logging
  4. Save the file and reload scripts in Ableton (Ctrl+Shift+R / Cmd+Shift+R)
  5. View logs in Ableton's Log.txt file

Log File Locations

Windows: C:\Users\[User]\AppData\Roaming\Ableton\Live [version]\Preferences\Log.txt
macOS: ~/Library/Preferences/Ableton/Live [version]/Log.txt

Making Changes to the Script

  1. Edit the .py files in the Launchpad95 folder
  2. Save your changes
  3. In Ableton: Ctrl+Shift+R (Win) or Cmd+Shift+R (Mac) to reload scripts
  4. Or restart Ableton Live completely

Common Issues

Launchpad doesn't light up

  • Check that the folder is named exactly Launchpad95
  • Verify Input and Output are set to correct MIDI ports
  • Try restarting Ableton Live
  • Check for Python syntax errors in Log.txt

Notes don't play in Instrument mode

  • Enable "Track" for both MIDI Input and Output in preferences
  • Make sure a MIDI track is selected with an instrument

Changes to script don't take effect

  • Use Ctrl+Shift+R to reload scripts
  • Or fully restart Ableton Live
  • Check for Python errors in Log.txt

Pro Session Mode

Pro Session Mode is the most powerful mode in Launchpad95, providing advanced clip manipulation, recording controls, quantization, and scene management - all without touching your computer. This is the mode professional users spend most of their time in.

Short press Session while in Session mode to activate
Key Concept: In Pro Session Mode, the 8 side buttons become "modifier" buttons. Hold a modifier and tap a clip to perform actions like delete, duplicate, quantize, etc. The system tracks button combinations via _modifier_count internally.

Timing Constants (Internal)

LONG_BUTTON_PRESS500msThreshold for long press actions in Pro Session & Instrument modes (redo, mute, implicit arm)
DOUBLE_CLICK_TIME250msDouble-click detection window (SHORT_PRESS = 0.25 in Pro Session)
VERY_LONG_BUTTON_PRESS2000msVery long press (implicit arm toggle in Instrument mode)
Note: The Step Sequencers (Drum & Melodic) define their own LONG_BUTTON_PRESS = 1.0 (1000ms), which is different from the 500ms used in Pro Session and Instrument modes.

Workflow Examples

Quick Recording Workflow

  1. Double-tap Double button to enable Fixed Length
  2. Hold Double + tap column 5 to set 4 bars
  3. Hold Record + tap empty slot to arm and start recording
  4. Recording automatically stops after 4 bars
  5. Hold Quantize + tap the new clip to quantize it

Copy/Paste Clips Between Tracks

  1. Hold Click + tap source clip (copies to clipboard)
  2. Navigate to destination track using arrow buttons
  3. Hold Click + tap empty destination slot
  4. Clip is pasted (clipboard remains until you copy another)

Building Arrangements with Scenes

  1. Record clips across multiple tracks
  2. Hold Shift + Click + tap row to launch all clips as scene
  3. Hold Shift + Double + tap to capture current playing state as new scene
  4. Use Shift + Duplicate + tap to duplicate scene for variations
  5. Use Shift + Quantize + tap to create empty scene for breakdowns
  6. Use Shift + Delete + tap to remove unwanted scenes

Live Performance Mixing

  1. Hold Delete + tap bottom row columns to mute/unmute tracks
  2. Hold Duplicate + tap bottom row columns to solo tracks
  3. Double-tap Delete to unmute all tracks instantly
  4. Double-tap Duplicate to unsolo all tracks instantly
  5. Hold Click + tap bottom row to control tempo

AUTORECORD Mode

AUTORECORD is a special mode that automatically arms tracks when you select them, eliminating the need to manually arm before recording.

How to Enable/Disable

Shift + Record (hold Shift, then press Record button)

Display shows: "AUTORECORD ON" or "AUTORECORD OFF"

Behavior

AUTORECORD OFF (default)Select track → Must press Arm → Then can record
AUTORECORD ONSelect track → Track arms automatically → Ready to record immediately

Use Cases

  • Jam sessions: Switch between instruments and record instantly
  • Live composition: Quickly capture ideas without extra button presses
  • Performance recording: Move between tracks seamlessly while recording

Internal Implementation Details

For developers modifying the script:

  • File: SessionZoomComponent.py (handles zoom/overview)
  • File: SpecialProSessionComponent.py (handles Pro Session clip operations)
  • Modifier tracking: _modifier_count tracks which modifiers are held
  • Clipboard: _slot_copy_buffer stores copied clip reference
  • Double-click detection: Uses _last_press_time with 250ms threshold
  • AUTORECORD flag: _record_mode_on tracks auto-arm state

6 Layout Modes

Instrument mode supports 6 different note layouts, selectable from the Scale Selection screen:

1. Chromatic (CHROMATIC)

All 12 notes in chromatic order. Each row shifts by the "row interval" setting (default 5 = perfect 4th).

  • All notes playable regardless of scale
  • Scale notes highlighted, out-of-scale notes dimmed
  • Good for: Jazz, chromatic runs, exploring outside the scale

2. Chromatic Guitar (CHROMATIC_GTR)

Chromatic layout with guitar-like tuning (rows shift by 5 semitones = perfect 4th, except one row shifted by 4 = major 3rd).

  • Mimics standard guitar tuning intervals
  • Familiar for guitarists transitioning to Launchpad

3. Diatonic (DIATONIC)

Only scale notes are shown. Each row shifts by a configurable interval within the scale (default 3 = thirds).

  • No "wrong" notes - every pad is in the scale
  • Vertical movement creates chord voicings
  • Recommended for beginners and live performance

4. Diatonic No Stagger (DIATONIC_NS)

Diatonic notes in strict horizontal rows without staggering. Each row is the same scale starting from different octaves.

  • Simple left-to-right scale runs
  • Each row is a complete octave of the scale

5. Diatonic Chords (DIATONIC_CHORDS)

Optimized for chord playing. Vertical columns form chord voicings.

  • Press multiple pads in a column for instant chords
  • Row intervals optimized for chord shapes

6. Drum Rack (DRUMRACK)

Automatically activated when selected track has a Drum Rack device. 4x4 drum pad layout matching Ableton's drum rack view.

  • Mirrors the 16-pad Drum Rack layout
  • Octave buttons shift through drum rack banks (4 pads per octave shift)
  • Automatic detection: switches to drum rack layout when you select a drum rack track

When enabled via very long press (>2s) on the Record button:

Device Lock System

Device locks allow you to "bookmark" up to 4 devices for instant recall, even when navigating to different tracks:

  1. To store a device: Navigate to the device, long-press Lock button (>400ms)
  2. To recall a device: Short-press the Lock button with stored device
  3. To clear a lock: Navigate to the stored device, long-press the same Lock button
NUM_DEVICE_LOCKS = 4
DEVICE_LOCK_LONG_PRESS = 0.4  # seconds
Pro Tip: Store your master EQ in Lock 1, compressor in Lock 2, synth in Lock 3, and effects in Lock 4 for instant access during performance.

Precision Mode

When Precision mode is enabled:

  • Each tap adjusts the parameter by a smaller increment
  • Allows values between the 8 standard grid positions
  • Essential for fine-tuning filter cutoffs, delays, etc.
  • Visual feedback shows current value with lit row

Workflow Examples

Quick Device Mixing

  1. Navigate to your synth track
  2. Enter Device Controller mode (User 1 x2)
  3. Adjust filter cutoff (typically column 3-4)
  4. Use Bank+ to access more parameters
  5. Store device in Lock 1 for quick recall

Live Performance Device Control

  1. Before performance, store key devices in Lock 1-4
  2. During performance, tap Lock buttons to jump between devices
  3. Use Precision mode for smooth filter sweeps
  4. Toggle device On/Off for effect drops

Drum Step Sequencer

Workflow Tips

Creating a Basic Drum Pattern

  1. Select a track with a Drum Rack
  2. Create/select a MIDI clip
  3. In Combined mode, use bottom-left 4x4 to select kick drum
  4. Tap steps in top half to place kick on beats 1 and 3
  5. Select snare from pad selector, add on beats 2 and 4
  6. Select hi-hat, add on all 8th notes
  7. Use Velocity+step to add dynamics to hi-hats

Extending Patterns

  1. Create pattern in first loop page
  2. Hold Velocity button
  3. Tap the NEXT loop page button (bottom-right)
  4. Pattern is duplicated to that page
  5. Edit the copy to create variation

Using Mute for Arrangement

  1. Create full pattern with all drums
  2. Hold Mute button
  3. Tap specific steps to mute them
  4. Duplicate page, unmute different notes for variation
  5. Muted notes shown in red - easy to see what's disabled

Lock Modes Explained

  • Unlocked (default): Sequencer follows session navigation - edit whatever clip is selected
  • Clip Lock: Sequencer stays on ONE specific clip, even if you navigate away in session
  • Track Lock: Sequencer stays on current track but follows which clip is selected on that track
Pro Tip: Use Track Lock when building a song - you can trigger different clips while the sequencer always shows the current drum clip on that track.

Workflow Examples

Creating a Chord Progression

  1. Enter Melodic Sequencer (User 2 x2)
  2. Make sure you're in Notes page (button 8)
  3. For step 1, tap rows 1, 3, and 5 to create a triad
  4. For step 3, tap different combination for next chord
  5. Switch to Length page (button 5), set all to 4 steps (1 beat)
  6. Switch to Velocity page (button 7), adjust dynamics

Creating a Bassline

  1. Double-press Notes button to enable Monophonic mode
  2. Tap notes for each step - only one note per step
  3. Switch to Octave page (button 6) to add octave jumps
  4. Switch to Length page, make some notes short (1 step) for staccato
  5. Press Random button while in Notes page for instant variation

Using Randomization Creatively

  1. Create basic pattern with notes you like
  2. Switch to Velocity page, press Random for humanized dynamics
  3. Switch to Octave page, press Random for register variation
  4. Switch to Length page, press Random for rhythmic interest
  5. Undo (in Session mode) if result isn't good

Scale Categories

Western Modes (0-6)

The 7 modes of the major scale. Each starts from a different degree of the major scale.

Bright to dark: Lydian → Ionian (Major) → Mixolydian → Dorian → Aeolian (Minor) → Phrygian → Locrian

Pentatonic Scales (11, 12)

5-note scales that work in almost any context. Great for improvisation and melodies.

  • Minor Pentatonic: Rock, blues, pop - the "safe" scale for soloing
  • Major Pentatonic: Country, folk, happy melodies

Blues Scales (10, 33)

Pentatonic scales with added "blue notes" for that classic blues sound.

  • Minor Blues: Dark, soulful - adds b5 "blue note"
  • Blues Major: Bright, happy blues - major pentatonic with chromatic passing tone

Japanese Scales (19-22, 27)

Traditional Japanese pentatonic and modal scales with distinctive intervals.

  • Hirojoshi: Peaceful, meditative
  • In-Sen: Dark, introspective
  • Iwato: Very dark, dissonant
  • Kumoi: Traditional koto music
  • Japanese: General-purpose Asian sound

Middle Eastern/Mediterranean (5, 16, 18, 24, 26, 30)

Scales with augmented seconds that create exotic, Eastern sounds.

  • Phrygian: Spanish/Flamenco foundation
  • Spanish: Full flamenco scale
  • Bhairav: North Indian morning raga
  • Minor Gypsy: Eastern European
  • Arabic: Middle Eastern double harmonic
  • Persian: Persian classical music

Symmetric Scales (7-9)

Scales with repeating interval patterns - useful for tension and resolution.

  • Diminished (Half-Whole): 8-note scale, alternating half/whole steps
  • Whole-Half: Same intervals starting with whole step
  • Whole Tone: 6 notes, all whole steps - no resolution

Frequently Asked Questions

The Launchpad doesn't light up when I select Launchpad95

Check that you installed the script in the correct MIDI Remote Scripts folder. The folder must be named exactly Launchpad95 (no "-master" suffix). Verify folder permissions and restart Ableton Live. See Troubleshooting for more details.

Note feedback isn't working in Instrument mode

Make sure to enable "Track" for both MIDI Input and Output in Live's MIDI preferences for the Launchpad ports.

Which Ableton Live versions are supported?

Launchpad95 works with Ableton Live 9.2 and later (32-bit or 64-bit, Mac or Windows, all editions).

Can I use multiple Launchpads?

Yes! Enable SESSION__LINK in Settings.py to link sessions between multiple Launchpad95 instances.

How do I see what the script is doing?

The script displays messages in Ableton's status bar (bottom of screen). For detailed debugging, enable Live.Base.log() statements in the Python files and check Log.txt. See Troubleshooting & Debugging.

How do I modify the script?

Edit the .py files in the Launchpad95 folder, save, then press Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac) to reload scripts without restarting Ableton.

What does the M4L Helper device do?

The optional Launchpad95Helper.amxd Max for Live device provides an on-screen display showing current mode, scale, and other settings. It's not required for the script to work.
